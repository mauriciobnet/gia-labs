Resultado esperado: As duas versões aparecem sem erro.

2

Ver a stack no ar

terminal✔ executado

Liste os containers do projeto. Os serviços da base (traefik, whoami, toolbox, openldap, lam, keycloak) devem estar "running" e, quando tiverem healthcheck, "healthy".

terminal · na pasta stack/
docker compose ps --format "table {{.Service}}	{{.Status}}"

Resultado esperado: Todos os serviços da base em running/healthy.

terminal✔ executado

Todo laboratório vai gravar um arquivo de evidência com o seu nome. Faça isto uma vez só: sem identificação o arquivo sai anônimo e não serve para o Moodle. Troque pelo seu nome e pelo seu RA.

python3 /work/scripts/evidencia.py aluno --nome "Seu Nome Completo" --ra 000000

Resultado esperado: A confirmação com o seu nome e o identificador desta instalação. O painel deixa de mostrar o aviso amarelo no topo.

4

Rodar a verificação do ambiente (check)

terminal✔ executado

O toolbox traz um script que valida arquitetura, memória, roteamento por hostname, LDAP, LAM, Keycloak e acesso ao registry.

terminal · na pasta stack/
docker compose --profile tools run --rm check

Resultado esperado: Todos os itens em [ OK ], a linha "LAB1 OK · código: ..." e, no fim, o caminho do arquivo de evidência gravado. O código curto serve para conferência em voz alta na aula; quem vale para o Moodle é o arquivo.

URL: http://whoami.localhost:18080/

Resultado esperado: Página de texto do whoami com Hostname, IP e os cabeçalhos da requisição.

6

Ver as rotas no painel do Traefik

navegador✔ executado

Abra http://traefik.localhost:18080. Cada container com label traefik.* aparece como um router (Host(`...localhost`)).

URL: http://traefik.localhost:18080/dashboard/#/http/routers

Resultado esperado: Lista de routers HTTP com whoami, lam, keycloak (e os dos labs seguintes).
